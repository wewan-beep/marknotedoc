# 功能详解

按使用场景拆开讲：每个功能解决什么问题、怎么操作、代码在哪、有什么限制。

## 一、登录与账号

![登录](/images/01-login.png)

- 登录、注册两个 Tab，回车即提交；新用户密码走 bcrypt
- 演示账号 `admin / 123456` 在 `sql/init.sql` 中预置，登录逻辑兼容明文与 bcrypt
- token 默认 24 小时，401 自动清 token 跳登录页

相关代码：`views/Login.vue`、`controller/UserController.java`、`util/JwtUtil.java`

## 二、三栏工作台

![工作台](/images/02-workspace.png)

| 区域 | 作用 |
| --- | --- |
| 左栏 | 笔记列表、搜索、全部/回收站切换、新建、重命名、删除 |
| 中栏 | Markdown 源码，顶部工具栏（图片 / 链接 / 加粗 / 代码块） |
| 右栏 | 公众号风格预览，宽度约 760px，与公众号正文一致 |

顶栏一条线放完所有动作：状态、新建、导入、保存、导出、主题、复制、同步滚动、暗色、历史、退出。

## 三、实时预览与同步滚动

- 输入即渲染（markdown-it），支持标题、列表、表格、引用、代码块、行内代码、KaTeX
- 代码块用 highlight.js，主题色由 CSS 变量控制，复制时颜色会内联
- 「同步滚动」开启后，左栏滚动按内容比例驱动右栏
- 顶栏显示 `14 行 · 268 字`，输入停顿 1.2 秒自动保存

## 四、新建与修改标题

这是迭代中修过一轮的功能，三个入口：

1. **顶栏标题框**：输入即置 dirty，0.9 秒防抖落库；回车立即保存并失焦
2. **列表悬停 ✏️**：弹框重命名，校验非空、≤80 字
3. **列表标题双击**：同弹框

两个细节：

- 新建后 `nextTick` 聚焦标题框并全选，直接打字就是新标题
- 正文首行正好是 `# 旧标题` 时，改名同步替换该行，避免「标题叫 A、正文第一行还是旧标题」

相关代码：`views/Editor.vue` 的 `commitTitle`、`renameNote`、`syncHeading`

## 五、导入 Markdown

![导入](/images/03-import.png)

- 顶栏「导入 MD」：多选 `.md / .markdown / .txt`，单文件 ≤ 5MB
- 左侧列表支持拖拽：出现蓝色虚线框「松开鼠标即可导入 .md 文件」
- 标题取正文第一个 `# 一级标题`，没有就用文件名（去扩展名，截 80 字）
- 导入前先 `flushSave()`，避免正在编辑的内容丢失
- 复用 `POST /note/add`，后端零改动

::: tip 批量迁移
把整个文件夹里的 md 逐个拖进列表即可；非 md/txt 文件会被忽略，不会打断整批导入。
:::

## 六、图片上传

![图片上传](/images/04-image.png)

三种入口，一条上传逻辑（`uploadOne(file)`）：

| 方式 | 操作 | 细节 |
| --- | --- | --- |
| 工具栏 | 「🖼 图片」选文件 | 支持多选，按光标位置顺序插入 |
| 拖拽 | 把图片拖进编辑区 | 蓝色遮罩「松开鼠标上传图片」 |
| 粘贴 | Ctrl+V 粘贴截图 | 剪贴板图片自动上传并插入 |

- 类型白名单：png / jpg / jpeg / gif / webp / bmp / svg，单张 ≤ 10MB
- 上传中右下角显示「图片上传中…」，多图顺序插入不串位
- 插入格式 `![文件名](url)`；「🔗 图片链接」则直接插外链
- 后端优先 MinIO，失败落本地 `uploads/`，URL 返回相对路径或绝对地址（取决于配置）

相关代码：`ImageController.java`、`MarkEditor.vue#uploadOne`、`api/image.js`

## 八、复制到公众号（核心功能）

![复制](/images/06-copy.png)

点「复制公众号 HTML」后：

1. 克隆预览 DOM 到离屏容器量样式
2. 每个节点计算样式全量内联、去掉 class
3. `pre` 转 `section`，换行转 `<br>`，高亮 token 颜色保留
4. KaTeX 降级为 TeX 文本，统计数量并提示
5. `ClipboardItem` 写 `text/html` + `text/plain`，失败走 `execCommand`

复制成功后提示「已复制「蓝调」主题（富文本 + 内联样式）」。

::: warning 三个已知行为
- 必须用 `localhost` 或 `https`，`http://` 局域网 IP 下会退化到兜底复制
- 公众号不支持 KaTeX，公式会成 TeX 文本，建议截图
- 公众号抓图需要公网可达的绝对地址，内网 IP 会裂图
:::

## 九、历史版本与回收站

- 每次保存写一条 `note_history`，`version` 自增；「历史版本」面板列出最近 50 条，选中可恢复
- 列表悬停「🗑」移入回收站；回收站可「恢复」或「彻底删除」
- 「导出 MD」把当前笔记下载为 `.md`，文件名取标题

## 十、其它细节

| 细节 | 行为 |
| --- | --- |
| 自动保存 | 正文 1.2s 防抖、标题 0.9s 防抖、回车立即保存 |
| 切笔记 | 先 flush 未保存内容再切换 |
| 暗色模式 | 只作用于编辑器 UI，不影响文章主题 |
| 字数统计 | 顶栏实时显示行数与字数 |
| 401 处理 | axios 拦截器清 token 并跳登录 |
